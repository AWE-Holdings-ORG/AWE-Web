# AWE Web

Official web platform for **AW Enterprises** and the **AWE Holdings** ecosystem.

## Purpose

This repository rebuilds and expands the earlier AW Enterprises Framer site as a maintainable, platform-independent web property.

The architecture preserves the original holding-company law:

> **AW Enterprises is the hub. The companies are the destinations.**

The current public-facing identity is **AWE Holdings**, the unified digital ecosystem of AW Enterprises.

## Current Site Map

- Home
- About AWE
- What We Build
- Our Ecosystem
- Technology / AWEOS
- Contact

## Brand Posture

The site should communicate:

- capability;
- discipline;
- ownership;
- selectivity;
- governance;
- long-term value.

Core line:

> **Ideas → Systems → Brands → Worlds → Legacy**

## Deployment

The site is configured for GitHub Pages through `.github/workflows/pages.yml`.

Custom domain:

`awenterprisesholdings.com`

The repository also contains a `CNAME` file for GitHub Pages custom-domain routing.

## Verification

Pinterest domain verification is included in the HTML head:

`p:domain_verify`
