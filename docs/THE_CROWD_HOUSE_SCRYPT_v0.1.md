# THE CROWD HOUSE SCRYPT v0.1

## Purpose
The Crowd is the first full interactive House inside the AW Enterprises Crown Network. It is not merely an archive page. The House is the web blueprint for the future CROWD SHYT application.

## Locked v0.1 zones
1. Crowd Player
2. Universal Judging Engine
3. Scoreboard / Rankings
4. Crowd Coin
5. The Archives
6. Official Network Signal

## Crowd Player law
- YouTube remains the media host for existing public Crowd videos.
- The web player embeds the official CrowdShyt YouTube uploads feed so playback is served by YouTube rather than duplicated on AWE storage.
- Future battle records will map specific YouTube video IDs to battle database records.
- Crown-exclusive media can use the same player shell with different entitlement rules.

## Judging law
- Archived battles: continuous voting.
- Archived battles: one final ballot per authenticated user.
- Archived ballots are immutable after submission.
- Live battles: judging opens for exactly 5 minutes after the battle ends.
- Live judging closes automatically after the server-controlled deadline.
- Live results may remain hidden until the voting window closes.
- v0.1 browser-local vote locking is a prototype only. Production enforcement requires authenticated user IDs and a server/database.

## App blueprint
The web House and future app share the same planned backend concepts: users, battles, media, ballots, judging windows, results, rankings, Crowd Coin balances, entitlements and archive metadata.
