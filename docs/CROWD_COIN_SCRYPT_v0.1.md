# CROWD COIN SCRYPT v0.1

## Phase 1: platform utility
Crowd Coin begins off-chain as an internal reward/access unit.

Potential earning sources:
- approved judging participation
- events
- verified platform activity
- campaigns and drops
- future partner activities

Potential uses:
- exclusive battle access
- early access
- digital drops
- profile features
- merch/ticket perks
- Crown Network unlocks

## Rare tier
“Black Coin” is retired as the working presentation name.
Current temporary name: LEGACY COIN.
Final naming remains open.

Legacy Coin concept:
- scarce status/provenance item
- founders and legacy contributors
- champions and special accomplishments
- limited historic/event drops
- not an ordinary spendable balance

## On-chain phase
No blockchain deployment occurs in v0.1.
Before any tradable/meme-coin launch:
- define real utility
- confirm brand/IP ownership
- select chain/token design
- complete legal/compliance review
- define custody/wallet model
- define supply, treasury, disclosures and security
- separate entertainment/reward mechanics from financial promises
